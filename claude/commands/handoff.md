# Handoff

Write `HANDOVER.md` in the current project directory with: goal, verified work and evidence, unfinished work, the first next action, decisions, constraints, files and git status, and open questions. If an existing handoff exists, preserve it without overwriting another backup. Never include secrets or invent test results. Do not commit or push unless asked. Report the path and a short resume instruction.
