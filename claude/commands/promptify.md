# Promptify

Turn `$ARGUMENTS` into a concise prompt for a fresh agent session. If no input is provided, ask for the idea. Identify the goal and relevant context, then specify concrete steps, constraints, evidence and success criteria appropriate to the request. Preserve the user's scope and intent; do not invent facts or requirements. If context is missing, mark it as unknown. Never include secrets. Return the prompt and a brief note on assumptions.
