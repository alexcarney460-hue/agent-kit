# Optional tools

These skills provide instructions only and are inert without their external tools or services. Installing the kit does not install or configure them.

- **reverse-engineer-anything:** REA MCP server or `rea` CLI. Its skill describes the version-pinned `rea-agents` npm package, a read-only doctor, and a setup dry run; native analysis may require additional engines.
- **obscura:** Obscura browser/CLI. The skill describes official release archives and Docker images, or building the source checkout with Cargo and the desired features.
- **typesafe-ai:** TypeSafe System One service/API or SDK. The skill points to the service documentation and Python and JavaScript SDK documentation.
